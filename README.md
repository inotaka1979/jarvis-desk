# ジャービス

相談・案件台帳・発注書づくりを 1 ページにまとめた個人用のページです。Claude の Artifact として公開して使います。

- 公開先：https://claude.ai/artifact/5tcFZEWn2gvCpboLV5qEz8 （非公開。持ち主だけが開けます）
- 原本：このリポジトリの `index.html`。公開先の内容は、ここから反映します。
- 台帳・会話・発注書・設定のデータは Claude 側の保存先にあり、このリポジトリには入りません。

## 構成

| 場所 | 中身 |
|---|---|
| `index.html` | ページ本体。HTML・CSS・JavaScript をすべて 1 ファイルに含む |
| `tests/` | テスト。Claude 側の機能を模した `stub.js` を使い、Chromium で実際に動かして確かめる |
| `.github/workflows/test.yml` | push のたびにテストを実行する |

## 画面と役割

| 画面 | 役割 |
|---|---|
| 相談 | 技術相談や壁打ち。返答の最後に台帳の更新が付いたら、台帳に反映して「取り消す」を出す |
| 台帳 | 案件の一覧と編集。「全体を見てもらう」で所見をもらう |
| 発注 | 依頼文から、発注先にそのまま渡せる発注書を作る |

頭脳と声は Claude、開発は Claude Code です。

## 使っている Claude の機能

| 機能 | 使いみち |
|---|---|
| `sample` | 相談の返答、所見、発注書 |
| `db` と `user` | 保存。`data/users/<本人のid>/` 以下に置くので、本人だけが読める |
| `tts` | 返答の読み上げ |
| `dictation` | 音声入力 |
| `downloads` | 発注書や書き出しファイルの保存 |

公開時の宣言は `{"db":{},"dictation":{},"downloads":{},"sample":{},"tts":{},"user":{}}` です。公開し直すときに省略すれば、そのまま引き継がれます。

## 変更して公開する手順

1. `index.html` を直す。
2. `npm test` で確かめる。初回だけ `npm ci` と `npx playwright install chromium` が要る。
3. コミットして push する。
4. Claude Code に「このリポジトリの `index.html` を公開先に反映して」と頼む。公開先の URL を指定して公開すれば同じページが更新され、保存データは残る。

## 守ること

- **見えない文字をソースに直接書かない。** コード記法の退避に使う目印は `` と `` のようにエスケープ表記で書く。直接書くとコピーの途中で落ち、数字がすべて `undefined` と表示される。テストで検査している。
- **設定・記憶・会話は、保存先から内容が届くまで書き込まない。** 空の状態で丸ごと上書きしないため。変更は `putPrefs`・`addMemory`・`dropMemory` を通す。届く前の変更は控えておき、届いた内容に重ねてから保存する。
- **画面に HTML として入れるのは `md()` の出力だけ。** それ以外の文字列は `textContent` で入れる。
- **読み上げをオフにされたら、端末の音声で代わりに読まない。**

## モデルの選び方

「考える深さ」が自動のとき、内容でモデルを選びます（`pickTier`）。

| モデル | 使う場面 |
|---|---|
| 速い | あいさつ、お礼、短い確認 |
| 標準 | ふだんの相談、進捗の報告、「はい」「続けて」などの返事 |
| じっくり | 比較・設計・原因・リスクなどを含む込み入った相談や長文 |

設定で固定でき、メッセージに「じっくり考えて」「手短に」と書けばその回だけ切り替わります。所見と発注書には速いモデルを使いません。

## テスト

`npm test` で 5 つのまとまりを順に実行します。保存先の遅れを再現する待ち時間を含むので、全体で 7 分ほどかかります。

| まとまり | 確かめること |
|---|---|
| `01-core` | 本文の組み立て、相談の流れ、台帳の更新、長文の文脈、モデルの選び方 |
| `02-store` | 保存と読み込み。遅れ、失敗、端末に残った控え、別の端末からの変更 |
| `03-ui` | ダイアログ、お知らせ、発注、ファイルの読み込み、音声、スマホ幅とダークモード |
| `04-extra` | 読み上げを途中でオフにされた場合、会話の読み込みだけが遅い場合 |
| `05-valve` | 保存先から控えしか届かない場合 |

`VERBOSE=1 npm test` で全出力、`SHOTS=1 npm test` で画面の写しを `tests/shots/` に保存します。1 つだけ実行するときは `node tests/03-ui.cjs D1` のように、まとまりと項目名の先頭を指定します。

テストは模擬の Claude 機能で動かしています。本物の保存先・音声・iPhone 実機での動きは、公開後に画面で確かめてください。
